# Delete content

```{warning}
When you delete content you delete the audio files from your {term}`pod`. Make sure you have a backup of any files you want to keep.
```

You can delete content at any time. To do this:

::::{tab-set}

:::{tab-item} Desktop
:sync: desktop

1. Log in to your pod.
2. Click on your profile
3. Go to Manage Upload
4. Select the uploads you want to delete
5. Click the delete button

:::
::::
That's it! You've successfully deleted the content from your library.
